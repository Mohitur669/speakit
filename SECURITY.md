# Security Policy

## Reporting a Vulnerability

The SpeakIT team takes the security of our platform and users seriously. If you believe you have discovered a vulnerability, please report it responsibly:

- **Do NOT open a public issue.** Public disclosure exposes users before a patch can be developed and distributed.
- **Preferred Method:** Report the vulnerability privately via [GitHub Security Advisories](https://github.com/Mohitur669/speakit/security/advisories/new).
- **Alternative Method:** Send an email with a detailed summary and proof of concept to **security@speakit.app**.

### What to Include in Your Report
- Detailed description of the vulnerability and attack vector.
- Step-by-step reproduction instructions or proof-of-concept (PoC) code.
- Potential impact and affected modules/versions.

## Supported Versions

| Version / Branch | Supported |
|---|---|
| `master` | :white_check_mark: |
| `release/*` | :white_check_mark: |

## Remediation Process

1. **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
2. **Investigation:** Our team will validate and investigate the issue.
3. **Patch & Release:** We will coordinate a security patch and credit the reporter (unless anonymity is requested).
