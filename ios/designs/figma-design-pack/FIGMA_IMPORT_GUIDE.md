# SpeakIT Figma-ready Design Pack

These files are **SVG vector mockups** sized to 390×844 and can be imported directly into Figma. They are based on the uploaded SpeakIT iOS Product Design & UX Specification.

## Import
Drag the SVGs into a Figma canvas or use File → Import. Convert repeated elements into components after import.

`design_tokens.json` contains the documented semantic colors, typography sizes, spacing, and component dimensions.

## Important
These are Figma-ready vector references, not a native `.fig` file. A native Figma file requires the Figma editor/connector itself.
